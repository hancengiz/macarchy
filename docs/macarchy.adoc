== Synopsis
[verse]
macarchy [-h|--help] [-v|--version] <subcommand> [<subcommand-options>...] [<subcommand-arguments>...]

== Description

Macarchy is an i3-like tiling window manager for macOS

*macarchy* command line program is used to manipulate Macarchy and query its state.

See https://nikitabobko.github.io/AeroSpace/commands for available <subcommand> options

See each <subcommand> individual man page for <subcommand-options> and <subcommand-arguments>

== Options

-h, --help:: Print help
